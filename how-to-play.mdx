Playing a game on Unblockedgames is as simple as clicking a tile — there are no installations, no account sign-ups, and no configuration required. Every game runs entirely inside your browser, so you can go from the homepage to actively playing in a matter of seconds. Here's exactly how it works.

## Launch a Game

<Steps>
  <Step title="Open the site">
    Navigate to the Unblockedgames homepage in any modern browser. You'll see a grid of game tiles, each displaying a thumbnail image and the game's name.
  </Step>
  <Step title="Pick a game">
    Click any game tile that catches your eye. You can also use the search bar or category filters to find a specific title — see [Finding Games](finding-games) for details.
  </Step>
  <Step title="Start playing">
    The game opens in a new browser tab and loads directly in your browser window. Most games are fully ready to play within a few seconds. Click inside the game window to give it keyboard focus before using any controls.
  </Step>
</Steps>

## Controls

Most games on Unblockedgames use standard keyboard and mouse controls that you're likely already familiar with. Each game also displays its own instructions or control guide on-screen — look for a help icon, an intro screen, or a pause menu within the game itself. The common controls across the library are outlined below.

<Tip>
  Before using keyboard controls, click inside the game window to give it focus. If your keystrokes aren't registering, clicking once inside the game area almost always fixes it.
</Tip>

<Tabs>
  <Tab title="Keyboard">
    Most games rely on a familiar set of keyboard inputs:

    - **Arrow keys or WASD** — move your character or navigate menus
    - **Space** — jump, fire, or trigger the primary action
    - **Enter** — start the game, confirm a selection, or advance through prompts

    Some games use additional keys (like `Z`, `X`, or `Shift`) for special moves. Check the in-game instructions for title-specific bindings.
  </Tab>
  <Tab title="Mouse / Touch">
    Many games support pointer-based input as well:

    - **Click or tap** — interact with objects, shoot, or select menu options
    - **Drag** — move characters or objects in games that support it
    - **Scroll** — zoom or navigate in applicable games

    On touchscreen devices, most tap-based games work out of the box. Keyboard-heavy games are best played on a physical keyboard.
  </Tab>
</Tabs>

## Game Loading

Different games on the platform use different underlying technologies, and each loads slightly differently.

**Flash games** — such as Bloons TD and Alien Hominid — are powered by the [Ruffle](https://ruffle.rs/) emulator, a WebAssembly-based tool that recreates Flash in the browser. These games may take a moment to initialize as Ruffle sets up. Once loaded, they behave just like the original Flash versions.

**Unity WebGL games** — such as Slope and Biters.io — display a loading progress bar before the game begins. Unity compiles a larger set of assets before launching, so the initial load can take slightly longer than simpler games. Once the progress bar completes, the game runs smoothly.

<Tip>
  For the best experience, use a modern browser like Chrome, Firefox, or Edge — and make sure JavaScript is enabled. These browsers offer the strongest support for both Ruffle and Unity WebGL.
</Tip>

## Fullscreen Mode

Many games on Unblockedgames support fullscreen play for a more immersive experience. Look for a fullscreen button built into the game itself — it's often found in the corner of the game window or inside a settings or pause menu. You can also press **F11** in your browser to expand the entire browser to fullscreen mode on most systems.

<Warning>
  Some games, especially Unity WebGL titles, may require a few seconds to load their assets before anything appears on screen. If a game looks frozen or blank, wait 15–30 seconds before assuming something is wrong. If it still doesn't load, try refreshing the tab.
</Warning>
