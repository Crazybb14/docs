Unblockedgames features a selection of local two-player games where two people compete on the same screen sharing one keyboard. Whether you want a quick basketball match, a chaotic physics brawl, or a tense race, every game in this category is designed for side-by-side play — no network setup, no second device, and no extra software required.

<Info>
  No Wi-Fi, accounts, or second devices required — both players sit at the same keyboard.
</Info>

## Controls at a Glance

Both players share one keyboard. The table below shows the default controls for every game in this category so you can get into the action without hunting through in-game menus.

| Game | Player 1 | Player 2 |
|---|---|---|
| Basketball Stars | WASD | Arrow Keys |
| Boxing Physics | W | Up Arrow |
| Dunkers Fight | W | Up Arrow |
| Multiplayer Pong | W / S | Up / Down Arrow |
| Rooftop Snipers 2 | W | Up Arrow |
| Fall Boys | A / D + W | Left / Right + Up |

  Select **Two Player** from the category dropdown on the homepage to see all 2P games at a glance.
</Tip>
