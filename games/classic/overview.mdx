Unblockedgames preserves a wide collection of classic browser and Flash games, all running directly in your browser without any plugin. From arcade mazes to block-stacking puzzles to tower defense strategy, these are the titles that defined a generation of browser gaming — and they are all playable right now, exactly as you remember them.

<Note>
  Flash games on Unblockedgames run through the **Ruffle** WebAssembly emulator — no Flash plugin or installation required.
</Note>

## About Ruffle

Ruffle is an open-source Flash Player emulator written in Rust and compiled to WebAssembly. It runs Flash (SWF) games inside modern browsers without requiring any plugin, browser extension, or external installation — the emulator loads invisibly alongside the game in the same browser tab.

Unblockedgames uses Ruffle to keep the Flash-era library alive after Adobe ended Flash Player support. When you launch a Flash game, Ruffle intercepts the SWF file and executes it through its WebAssembly runtime, so the game behaves almost identically to how it did in the original Flash Player.

Not every Flash game is fully supported — some older or more complex SWF files may have minor visual glitches or unsupported features. However, the most popular classic Flash titles including Bloons TD 1 and 2 work well and are regularly tested against new Ruffle releases.
