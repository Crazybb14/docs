Have a game you'd love to see on Unblockedgames? There are two easy ways to request it — GitHub Issues and Discord. The more detail you include, the easier it is for the maintainer to find, test, and embed the game.

## Option 1: GitHub Issues

GitHub Issues is the preferred channel for game requests because it creates a permanent, trackable record that the maintainer can review at any time.

<Steps>
  <Step title="Open the Issues page">
    Go to [https://github.com/Crazybb14/unblockedgames/issues](https://github.com/Crazybb14/unblockedgames/issues).
  </Step>
  <Step title="Click 'New Issue'">
    Click the green **New Issue** button in the top-right corner of the Issues page.
  </Step>
  <Step title="Select the Feature/game request template">
    Choose the **Feature/game request** template from the list of issue templates. This pre-fills the issue with the fields the maintainer needs.
  </Step>
  <Step title="Fill in the request details">
    Complete the template fields: the game name, a link to where the game can be found, and a short explanation of why you'd like it added to the site.
  </Step>
  <Step title="Submit your request">
    Click **Submit new issue**. The maintainer reviews requests periodically and will respond or close the issue once it's been acted on.
  </Step>
</Steps>

<Tip>
  Include a direct link to the game — for example, a URL from itch.io, Poki, or another browser game site. A working link lets the maintainer find and embed the game much faster than a title search alone.
</Tip>

## Option 2: Discord

For a more casual suggestion or a quick chat about potential additions, the Discord server is a great option.

1. Join the community server: [https://discord.gg/xksWyP9aJv](https://discord.gg/xksWyP9aJv)
2. Post your game suggestion in the appropriate channel.
3. Other community members can upvote or discuss your idea, which helps the maintainer gauge interest.

Discord is also a good place to follow up on a GitHub request or find out whether a game is already planned.

## What Makes a Good Request

A well-written request is more likely to be picked up quickly. Include the following:

- **Game title** and a brief description of what the game is
- **A direct link** to the game source (itch.io, Poki, CrazyGames, Kongregate, etc.)
- **Why it fits the site** — confirm that it's browser-playable and requires no download, account, or special software

<Warning>
  Games that require a download, a paid account, or any software installation cannot be embedded on Unblockedgames. Only free, browser-playable games are eligible for the platform.
</Warning>

## Reporting a Bug

If you've found a broken game or a site issue rather than wanting to request something new, use the **Bug report** template instead:

1. Go to [https://github.com/Crazybb14/unblockedgames/issues](https://github.com/Crazybb14/unblockedgames/issues) and click **New Issue**.
2. Select the **Bug report** template.
3. Fill in the following details:
   - The name of the affected game
   - Your browser name and version
   - What you expected to happen
   - What actually happened (include any error messages you see)

Clear bug reports get resolved faster — the more detail you provide, the less back-and-forth is needed.
