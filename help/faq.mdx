Here are answers to the most common questions about using Unblockedgames — from how the site works to why games load where other sites might be blocked.

<AccordionGroup>
  <Accordion title="Do I need to create an account?">
    No. Unblockedgames requires no login or registration of any kind. Just open the site and start playing — there are no sign-up forms, email addresses, or passwords involved.
  </Accordion>

  <Accordion title="Is Unblockedgames free?">
    Yes, completely free. There is no subscription, paywall, or payment required to access any game or streaming link on the site.
  </Accordion>

  <Accordion title="Why are the games 'unblocked'?">
    The site is hosted on GitHub Pages and similar platforms that most school and workplace network filters allow through by default. Games run directly in the browser without requiring any blocked software, app installs, or special permissions.
  </Accordion>

  <Accordion title="Do I need to install anything?">
    No downloads or plugins needed. Flash games use the built-in Ruffle emulator, which runs entirely in WebAssembly inside your browser — no Flash Player plugin required. Unity WebGL games run natively in all modern browsers.
  </Accordion>

  <Accordion title="Which browsers work best?">
    Chrome, Firefox, and Edge all work well with the full game library. Safari may have issues with some Unity WebGL games. Keep your browser updated to the latest version for the best performance and compatibility.
  </Accordion>

  <Accordion title="Does it work on mobile?">
    Most games work on mobile browsers, though some keyboard-heavy games are designed with desktop play in mind. Two-player games in particular require a physical keyboard and are not well-suited for touchscreen devices.
  </Accordion>

  <Accordion title="Will my game progress be saved?">
    It depends on the game. Some games — like Cookie Clicker — automatically save your progress to your browser's local storage, so it persists between sessions. Other games start fresh every time you open them. Clearing your browser's cache or local storage will erase any saved data.
  </Accordion>

  <Accordion title="How many games are available?">
    Over 160 games are available across multiple categories including action, arcade, idle, sports, and two-player titles, with new games added periodically based on community requests.
  </Accordion>

  <Accordion title="Can I suggest a new game?">
    Yes! You can submit a game request in two ways:
    - **GitHub Issues:** [https://github.com/Crazybb14/unblockedgames/issues](https://github.com/Crazybb14/unblockedgames/issues)
    - **Discord:** [https://discord.gg/xksWyP9aJv](https://discord.gg/xksWyP9aJv)

    See the [Request a Game](/help/request-a-game) page for tips on writing a request that gets picked up quickly.
  </Accordion>

  <Accordion title="A game isn't loading — what do I do?">
    Start with a hard refresh of the tab using **Ctrl+Shift+R** (Windows/Linux) or **Cmd+Shift+R** (Mac). If that doesn't help, check out the full list of fixes on the [Troubleshooting](/help/troubleshooting) page.
  </Accordion>
</AccordionGroup>
