Unblockedgames gives you two tools to cut straight to the game you want: a real-time search bar that filters titles as you type, and a category dropdown that groups games by genre or type. You can use each one on its own or combine them to zero in on exactly what you're looking for.

## Search Bar

The search bar sits at the top of the homepage grid. Start typing and the game grid updates instantly — no need to press Enter or click a button. Filtering is case-insensitive, so "SLOPE", "slope", and "Slope" all return the same result. The search matches against game titles only.

**Examples:**
- Type `slope` → Slope appears in the grid
- Type `mario` → Mario titles appear in the grid

<Tip>
  Even partial matches work — type `sub` and you'll find Subway Surfers without needing to type the full name.
</Tip>

## Category Filter

The category dropdown sits at the top of the homepage, next to the search bar. Click it to reveal the available filters and select one to instantly re-sort the game grid.

| Filter | What it shows |
|---|---|
| All | Every available game |
| Popular | Fan-favorite titles (Slope, Minecraft, 1v1.lol, etc.) |
| Two Player | Games supporting 2 players on one keyboard |
| Streaming | Movie and TV streaming links |
| Bad Games | Joke and novelty games |

## Combining Search and Filter

Search and the category filter work together at the same time. For example, select **Two Player** from the dropdown and then type `dunk` in the search bar — the grid will narrow to two-player games whose titles contain "dunk," surfacing Dunkers Fight right away.

<Info>
  Filters stack — applying a category first and then typing in the search box filters within that category, not across all games.
</Info>

## Browsing the Grid

When no search term is entered and **All** is selected, the full game library is displayed as a thumbnail grid. Each tile shows the game's icon and title. Click any tile to launch that game — it opens in a new browser tab at `/play/<game-slug>/`, so your place in the grid is waiting for you when you come back.
