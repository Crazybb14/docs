Several games on Unblockedgames support local two-player play — two people compete on the same screen using one keyboard, with each player assigned a different set of keys. It's the fastest way to challenge a friend sitting right next to you without needing a second device, account, or internet lobby.

## How Local Multiplayer Works

Local multiplayer on Unblockedgames is entirely self-contained. There is no network connection needed between players, no second device, and no account to sign in to. Both players sit at the same keyboard and use their assigned keys simultaneously.

Player 1 typically controls their character with **WASD** or keys on the left side of the keyboard. Player 2 typically uses the **arrow keys** or keys on the right side. The exact layout varies by game.

<Info>
  Key assignments vary by game. Check the controls displayed on each game's loading screen or in-game help panel for the exact bindings before you start.
</Info>

## Controls Overview

The table below shows the default controls for the two-player games currently available on Unblockedgames:

| Game | Player 1 | Player 2 |
|---|---|---|
| Basketball Stars | WASD + G/H | Arrow Keys + L/K |
| Boxing Physics | W | Up Arrow |
| Dunkers Fight | W | Up Arrow |
| Rooftop Snipers 2 | W | Up Arrow |
| Multiplayer Pong | W / S | Up / Down Arrow |
| Discus | W | Up Arrow |

## Finding Two-Player Games

To browse the full selection of two-player games, open the category dropdown at the top of the homepage and select **Two Player**. The grid will filter down to show only games that support two players on one keyboard.

You can also explore the full list in the sidebar under `categories/two-player` and `games/two-player/overview`.

<Tip>
  Two-player games work best on a full-size keyboard — compact laptop keyboards can make it cramped for two players to reach their keys comfortably at the same time.
</Tip>
